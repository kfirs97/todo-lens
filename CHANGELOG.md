# Changelog

## 0.1.4

- GDScript (Godot) support — highlighting and the TODO tree now work in `.gd` files, even without a Godot extension installed (thanks @kewlfrogz, #1).
- 25+ more languages: GDScript, Godot shaders, WGSL, QML, Arduino, Verilog/SystemVerilog, Gleam, Odin, Prisma, Mojo, Nushell, Raku, AWK, HCL, Starlark/Bazel, Fortran, AutoHotkey, Assembly, Pascal, Stylus, Nim, Crystal and more.
- Languages TODO Lens doesn't know yet are now highlighted using the common comment styles (`//`, `#`, `/* */`) instead of being ignored.

## 0.1.3

- Pro features are now free for your first 7 days (no signup). A single reminder appears when the trial ends.

## 0.1.2

- Asks once for a rating after a week of regular use (never shown again after any answer).

## 0.1.1

- Sponsor button on the extension page
- Links to the other Branchline extensions

## 0.1.0

First release.

- Better comments: color `!` alerts, `?` questions, `*` highlights, `//` struck-out code, and TODO/FIXME/BUG/HACK/XXX/NOTE tags in 60+ languages
- TODO tree grouped by file or tag, live updates on save/create/delete, activity bar badge and status bar count
- Custom tags and exclusions
- Pro: TODO age & author from git blame, "my TODOs" filter, Markdown TODO report
